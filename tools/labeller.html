How to

New player: drag a box on empty space (gets a new ID).
Known player: click their ID in the list, then drag the box (one box per click).
Edit: click a box to select it, drag it to move, drag a corner to resize.
Same player = same ID on every frame. Not visible on a frame → no box.
Occluded: partly hidden but you can still draw where they are.
Ignore region: crowds or bench areas that should not be scored.
Zoom: mouse wheel. Pan: right-drag or Space+drag.
